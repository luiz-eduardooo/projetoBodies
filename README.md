# 🍼 projetoBodies — E-commerce para Confecção de Roupas de Bebê

E-commerce completo desenvolvido para uma confecção de roupas de bebê. A aplicação permite o gerenciamento de produtos e todo o fluxo de compra pelo próprio site, com uma interface moderna e limpa.

> Projeto desenvolvido em dupla, como parte da minha prática em desenvolvimento full stack.

---

## ✨ Funcionalidades

- Cadastro, edição, listagem e exclusão de produtos (CRUD completo)
- Criação de pedidos e fluxo de compra pelo site
- Upload de imagens de produtos
- Interface responsiva, moderna e clean

---

## 🛠️ Tecnologias

**Front-end:** React · TypeScript · CSS
**Back-end:** Node.js · TypeScript
**Banco de dados:** PostgreSQL

---

## 👤 Meu papel no projeto

O projeto foi desenvolvido em dupla. Atuei principalmente no back-end, sendo responsável por:

Construção dos controllers, entidades, rotas e configuração do servidor
Sistema de autenticação
Criação das migrations do banco de dados
Integração com a API do Mercado Pago para os métodos de pagamento

Também auxiliei na integração da API no front-end e fui responsável pelo design system do projeto (paletas de cores, tipografia e identidade visual).

## 🚀 Como rodar o projeto

### Pré-requisitos
- Node.js instalado
- PostgreSQL instalado e em execução

### Back-end
```bash
cd backend
npm install
npm start
```

### Front-end
```bash
cd frontend
npm install
npm start
```

> Lembre-se de configurar as variáveis de conexão com o banco de dados antes de iniciar o back-end.
